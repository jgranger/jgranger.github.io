# Agentic Journey

We built our first AI agent to get some of our evenings back. At momoGood we were investigating messaging incidents after hours and wanted to do more of that work right in Slack. What started with one problem worth solving changed how I think about what people and agents can learn together.

In *Agentic Journey* I tell the story of how we built and ran these systems in production. An agent traces a production error back to the code and the decisions behind it. An automated evaluation gives us better scores while people get worse answers. A question an agent can't answer brings together colleagues who can. Each story comes back to a question I call operational context. What do we need to know to make the next move?

The book follows that question from search and evaluation to the way an organization learns. An agent can help someone find the evidence they need to act. A colleague can bring the experience that changes what they do next. What they learn together can give the next person a better place to start.
